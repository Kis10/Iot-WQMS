1 · ESP32 IoT Device (Firmware)

The AquaSense sensor reads pH, TDS, Turbidity, Temperature every cycle and POSTs JSON payload to the Laravel API via HTTP.

aquasense.ino
🖥

2 · API Ingestion (Laravel Controller)

The POST /api/data endpoint validates the payload, identifies the device by device_id, saves raw sensor data and upserts a snapshot into latest_readings.

deviceswater_readingslatest_readings
🤖

3 · AI Analysis Job (Scheduled / Queued)

Every 5 minutes, AnalyzeWaterQuality job runs via the job queue. It reads the latest water reading, calls the Gemini AI API, and persists safety/quality insights, risk level, recommendations and confidence score.

water_readingswater_analysesjobs
🚨

4 · Alert Generation

When sensor values breach thresholds (pH critical, TDS > 1500, Turbidity < 20, Temp outside 15–35 °C), alert records are written and broadcast via SSE to the dashboard in real-time.

alerts
👤

5 · User Authentication & Access

Users register, verify email (OTP), and await admin approval. On login, a login_activities record is created. Every page action is logged to user_activities. Session state persists in sessions.

userssessionslogin_activitiesuser_activitiespassword_reset_tokens
💬

6 · AI Chat Assistant

Authenticated users interact with an AI chatbot. Each prompt and AI reply is stored linked to the user, building a conversation history.

chat_messagesusers
🎨

7 · Landing Page CMS

Admins edit landing page content (text, images, HTML blocks) through an inline editor. Changes are persisted as key-value pairs in landing_contents.

landing_contents
